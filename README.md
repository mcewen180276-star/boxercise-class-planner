# Boxercise Class Planner V7.2

Complete static, free GitHub Pages application. Upload **all files in this ZIP to the root** of your existing `boxercise-class-planner` repository, overwriting older files. Keep the same URL and browser to preserve local saved classes.

## Before updating
Open the old app and export a full JSON backup from Saved Classes. Save the backup somewhere safe. The V7 app retains the original `boxercise-planner-v1` localStorage key and old class/custom exercise formats; it adds new fields rather than replacing the existing ones. No cloud sync or account is required.

## Features
- Redesigned dashboard and class builder
- Equipment quantities and station-aware class generation
- Pairs and threes group and rotation display
- Reorder exercises, change section durations, save templates
- Full-screen live teaching and optional spoken cues
- Expanded written exercise library and combination cues
- Station-card printing and full plan printing
- Multiweek schedules assembled from saved classes, history log
- Full JSON backup and restore
- Existing icon and PWA installation configuration

## Limitations
Equipment allocation is a planning aid: instructor must check physical space, sharing, gloves and pad sets per group. Programmes rotate saved classes rather than automatically escalating training load. The app uses local browser storage; deleting site data removes local records unless a backup exists. Spoken cues and full-screen support depend on browser. Internet demonstration links are not automatically verified.

## V7.2 station teaching update
- Station cards give exercise-specific steps and explicit roles for pairs or threes.
- Padwork trios rotate boxer, pad holder and shadowboxer so all three have equal turns.
- Shared-equipment stations include equipment-free alternatives and timed swaps.
- Print station cards now include role instructions.
- Existing local data keys and icon files are unchanged.
